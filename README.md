# CodeAlpha Login & Registration System

## Description
This project is developed as part of the CodeAlpha C++ Programming Internship.

## Features
- User Registration
- User Login
- Stores username and password in a file
- Verifies login credentials
- Console-based application

## Technologies Used
- C++
- File Handling

## How to Run
1. Open the project in Code::Blocks.
2. Build and Run the program.
3. Choose Register or Login from the menu.
